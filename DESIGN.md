# Well Kept Design Context

## Visual System

The interface should mirror the supplied mobile references: warm off-white background, deep green action color, editorial serif titles for brand-level moments, compact sans-serif UI text, soft elevated cards, thin green selected states, and bottom sticky actions.

## Color

- Background: warm ivory, never pure white.
- Surface: lightly tinted cream and soft white.
- Primary: deep residential green.
- Text: warm charcoal.
- Muted text: olive gray.
- Borders: low-contrast sage and stone.
- Semantic colors: green for success/open, amber for warnings, muted red for destructive errors.

## Typography

- Brand and major screen titles use a classic system serif stack.
- Product UI, labels, forms, and data use a native sans stack.
- Bid amounts and counts use tabular numerals.
- Keep headings measured and readable on 320px screens.

## Components

- Cards should be action boundaries, not decoration.
- Use soft shadows sparingly for tappable job and bid cards.
- Selected or recommended bid cards use a green border and very light green background.
- Forms use visible labels, segmented controls, and card selectors.
- Sticky bottom action bars are expected on mobile for posting and accepting.

## Responsive Rules

- Base styles are mobile-first.
- Bottom navigation must respect safe area padding.
- Controls must be at least 44px tall.
- Tablet and desktop may widen content, but should not introduce a separate product concept.
